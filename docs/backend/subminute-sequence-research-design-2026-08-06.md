# 5초 이벤트 순서 전략 연구 설계

## 문제

기존 프로그램은 Bybit 호가와 체결을 1분 단위로 집계했다. 이 데이터는 한 분 안에서 공격 체결, 가격 충격, 유동성 제거·보충, 반대 흐름 확인이 어떤 순서로 발생했는지 보존하지 않는다. 사전 선언한 191개 후보는 인과적 비용 차감 후 승인 조건을 통과하지 못했으므로 같은 집계값을 다시 조정하지 않는다.

## 목표

- 공식 원시 아카이브를 5초 반개구간 버킷으로 재생한다.
- 호가 `cts`, 체결 거래소 시각, OI 5분 관측, 실제 펀딩 정산 시각을 의사결정 시점 기준으로 결합한다.
- 지속과 반전을 별도 가설로 유지한다.
- 2023년 선택과 2024년 내부 검증을 시간순으로 분리한다.
- 통과 후보가 있을 때만 잠긴 확장·2025·2026 데이터를 단계적으로 연다.

## 비목표

- 일복리 목표에 맞춰 후보나 문턱을 사후 변경하지 않는다.
- 공개 L2에서 개별 주문 취소나 정확한 maker queue를 추정하지 않는다.
- 과거 청산 이벤트가 없는 상태를 청산 0으로 해석하지 않는다.
- 연구 결과만으로 자동 주문 또는 실거래를 허용하지 않는다.

## 데이터 흐름

```text
공식 orderbook ZIP + public trade CSV.GZ
  -> 원본 SHA-256 및 기존 일별 manifest 대조
  -> 5초 호가/체결 버킷
  -> OI·펀딩 point-in-time 결합
  -> 2023 후보 선택
  -> 2024 내부 검증 및 1.5배 비용 스트레스
  -> 통과 시에만 잠긴 다음 증거 단계
```

호가 버킷은 마지막으로 인과적으로 관측한 장부를 전달할 수 있지만 전달 여부를 별도 필드로 기록한다. 체결이 없는 버킷은 거래량 0으로 기록하며 미래 체결 가격을 채워 넣지 않는다. 결정은 완성된 5초 버킷 뒤에만 가능하고 진입은 그 이후 처음 관측한 장부에 시장가 비용을 적용한다.

## 가설

### 흡수 반전

닫힌 M15 추세에 반대되는 공격 흐름이 발생했지만 가격 충격이 제한되고, 소비된 호가가 보충되며, OI가 감소한 뒤 반대 체결과 microprice가 확인되면 기존 포지션 정리 흐름이 소진됐다는 가설이다.

### 고갈 지속

닫힌 M15 추세 방향의 공격 흐름이 가격 충격을 만들고, 반대편 호가가 제거된 뒤 충분히 보충되지 않으며, OI가 증가하고 같은 방향 체결과 microprice가 확인되면 신규 포지션 유입이 추세를 지속시킨다는 가설이다.

## 검증 계약

- 후보 수: 가족별 16개, 총 32개 고정
- 선택: 2023년 네 분기, 최소 24거래와 양방향 표본 필요
- 내부 검증: 2024년 네 분기, 최소 20거래와 3개 양수 분기 필요
- 통계: 일별 R moving-block bootstrap 5,000회, 95% 하한 0 이상
- 비용: taker 왕복 수수료 0.12%, 왕복 슬리피지 0.04%, 내부 검증 1.5배 비용 스트레스
- 위험: MDD 15% 이하, 모의 청산 0, 최대 승자 이익 집중도 35% 이하
- 실행: 동일 5초 내 TP/SL 충돌은 손절 우선, 하루 최대 5회, 포지션 중첩 금지

## 완료 조건

데이터 수집기는 일별 17,280개 호가 버킷, 명시적 0 체결 버킷, 원본 해시, 이벤트 시각 경계, OI·펀딩 시점 정합성을 재현해야 한다. 전략은 2023 선택과 2024 내부 검증을 모두 통과하기 전에는 다음 데이터를 읽을 수 없다. 최종 실거래 승인은 이후의 독립 검증, 비용·지연·자본 스트레스, Kotlin 실행 정합성, Shadow/Paper 전진 검증까지 별도 통과해야 한다.

## 선택 평가 계약

- M15 방향, M1 ATR, M5 OI는 각 관측값이 닫히거나 게시된 뒤의 5초 결정에만 전달한다.
- 충격 버킷은 10초 또는 20초이며, 사전 30분 5초 명목 거래량 중앙값에서 현재 충격 버킷을 제외한다.
- 충격 뒤 최대 30초 안에 진입 방향 체결 불균형, microprice, 가격 이동이 처음 함께 확인된 시점을 사용한다.
- 집계 자료가 버킷 시작 호가를 보존하지 않으므로 확인 직후 다음 5초 버킷이 닫힐 때, 확인 호가와 다음 호가 중 불리한 가격에 시장가 슬리피지를 더한다. 이 지연은 5초이고 사전 한도 10초 안이다.
- 진입 이후 첫 5초부터 체결 고가·저가를 재생하며 같은 버킷에서 손절과 목표가가 모두 닿으면 손절을 먼저 적용한다.
- 손절 거리는 `max(M1 ATR × 1.25, 체결가 × 0.4%)`, 목표는 3R, 최대 보유는 60분이다.
- 수량은 계좌 1% 위험, 100 USDT 최대 명목가, 15배 최대 레버리지 중 가장 작은 값에서 0.001 BTC 단위로 내림한다. 최소 수량이 위험 한도를 넘으면 거래하지 않는다.
- 진입·종료 taker 수수료 각 0.06%, 양쪽 슬리피지 각 0.02%, 보유 중 실제 펀딩 정산을 모두 순손익에 반영한다.
- 후보는 고정된 32개 전부를 평가하고, 가설군마다 사전 선택 게이트를 통과한 1개만 2024 내부 검증 후보로 동결한다. 통과 후보가 없으면 2024 자료를 수집하지 않는다.

## 수집 실행

2023 선택 데이터만 먼저 수집한다.

```bash
node scripts/subminute-sequence-acquire.mjs \
  --protocol=config/bybit-subminute-sequence-development-v1.json \
  --stage=selection
```

수집은 일별 호가와 체결을 각각 독립 트랜잭션으로 확정한다. 프로세스가 중단되면 같은 명령을 다시 실행해 SHA와 17,280개 버킷이 이미 일치하는 일별 자료를 건너뛴다. 원본 크기, SHA, 이벤트 수, 첫·마지막 시각 또는 1분 재집계값 중 하나라도 기존 증거와 다르면 해당 날짜를 실패 처리한다.

2024 내부 검증 자료는 2023 후보가 고정된 뒤에만 다음 명령으로 수집한다.

```bash
node scripts/subminute-sequence-acquire.mjs \
  --protocol=config/bybit-subminute-sequence-development-v1.json \
  --stage=internal-validation
```

## 2023 선택 데이터 결과

선택 단계 28일 수집을 완료했다. 공식 압축 원본 기준 호가 `24,056,461`건과 체결 `21,305,955`건을 처리했고, 호가·체결 각각 `483,840`개의 5초 버킷을 만들었다. 호가 전달 버킷은 0개였고 체결이 없었던 `10,486`개 버킷은 거래량 0과 가격 없음으로 유지했다.

읽기 전용 선택 snapshot은 `build/research/bybit-subminute-sequence-development-v1-selection.sqlite`에 봉인했다. snapshot SHA-256은 `bb7b95dda9de96835b4288a0e35ff03a4ed27d39d32caf5a85923b8b6e93e15f`, 정규화 특징 SHA-256은 `ba3265dd57cae8b008fbb433e131c94c4b9521342e64b77238a763a4b85a83c9`다. mutable 수집 DB의 SQLite 페이지 해시는 증거로 사용하지 않는다.

## 2023 선택 결과

고정 후보 32개 중 선택 게이트를 통과한 후보는 `0개`다. 흡수 반전 16개 중 8개가 미세한 양수였지만 최고 후보도 24일 동안 11회만 거래했고, Long 1회·Short 10회, 양수 분기 1개, 최대 승자 집중도 49.23%였다. 누적 수익률은 `+0.77550%`, 일복리는 `+0.03219%`로 선택 조건을 충족하지 못했다. 고갈 지속 16개는 전부 손실이었다.

주된 구조적 원인은 절대 microprice 확인값이다. Q1 평균 관측 스프레드는 `0.11383bps`였지만 Q2~Q4에는 `0.03313~0.03762bps`로 줄었다. 이에 따라 `|microprice edge| >= 0.05bps`인 5초 버킷 수가 Q1 `26,747개`에서 Q2~Q4 `5개`, `7개`, `3개`로 붕괴했다. 이는 Q1 성과가 범용적인 흐름 확인이라기보다 특정 호가 척도에 종속됐다는 증거다.

v1 프로그램은 `CLOSED_NO_APPROVABLE_SUBMINUTE_SEQUENCE_STRATEGY_V1`으로 종료한다. 임계값만 낮춰 같은 프로그램을 다시 돌리지 않는다. 다음 연구는 microprice를 동시점 스프레드로 정규화하는 새 특징 계약과 새 후보 예산을 결과 재생 전에 선언해야 한다. 2024 내부 검증과 이후 자료는 읽지 않았으며 자동·실거래 권한은 계속 닫혀 있다.
