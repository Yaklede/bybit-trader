# 이벤트 흐름 스윕 실패 반전 v1 결과

## 판정

고충격 유동성 스윕이 완전히 되돌려진 뒤 반대 방향으로 진입하는 가설도 `REJECTED_FAILED_SWEEP_REVERSAL`로 종료한다. 2023년 선택 구간에서 16개 후보가 모두 음수이고 bootstrap 구간 전체가 0 아래였으므로 2024 후보 선택은 수행하지 않았다.

## 2023 선택 결과

| 항목 | 범위 |
|---|---:|
| 후보 수 | 16개 |
| 후보별 거래 | 24~66건 |
| 순수익률 | -10.4731% ~ -4.0897% |

| Profit factor | 0.1745 ~ 0.3403 |

가장 높은 순위의 `fsr_cw10_ci0p1_rn1_ob0p05`도 66거래, `-10.4731%`, 평균 `-0.3338R`, PF `0.3258`이었다. 평균 R의 bootstrap 95% 범위는 `-0.4524R ~ -0.2062R`로 전부 음수다.

## 비용 전후 분해

최상위 후보의 수수료 차감 전 평균은 슬리피지를 포함해 `-0.1114R`였고, 평균 수수료가 `0.2223R`를 추가로 차감해 최종 `-0.3338R`가 됐다. maker 체결이나 수수료 인하가 손실을 줄일 수는 있지만, 비용 전 기대값도 음수이므로 이 전략을 수익 전략으로 바꾸지는 못한다.

종료는 손절 23건, 목표 3건, 시간 종료 39건, 블록 종료 1건이었다. Long 평균은 `-0.1396R`, Short 평균은 `-0.5400R`였지만 결과 확인 후 Short를 차단하면 사후 최적화다. 이 가족은 방향 필터 없이 그대로 폐기한다.

## 종합 해석

이벤트 흐름 데이터에서 지금까지 검증한 즉시 지속, 즉시 흡수 반전, 반대 흐름 확인 반전, 같은 흐름 확인 지속, 스윕 실패 반전은 모두 독립적인 수익 근거를 만들지 못했다. 거래량 폭발 자체와 1분 집계 호가 흐름만으로 다음 수 시간의 방향을 안정적으로 예측하기 어렵다는 증거가 누적됐다.
