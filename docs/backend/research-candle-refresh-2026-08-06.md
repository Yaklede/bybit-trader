# 연구 캔들 데이터 증분 갱신 결과

## 목적과 범위

`build/runtime-test/bybit-trader-full-history.sqlite`의 BTCUSDT Bybit linear
M1/M5/M15 캔들을 기존 마지막 시각 이후부터 증분 갱신했다. 목적은 다음 전략
연구의 데이터 기준선을 최신화하는 것이며, 기존 봉인 검증 구간을 확장하거나 전략
성과를 새로 주장하는 작업은 아니다.

- 원천: Bybit V5 public `GET /v5/market/kline`
- 갱신 시각: `2026-08-06`
- 공통 종료 경계: `2026-08-06T00:15:00Z` exclusive
- 저장 대상: 닫힌 캔들만 포함

## 갱신 결과

| 시간 프레임 | 갱신 전 행 | 신규 고유 행 | 갱신 후 행 | 최초 시각 | 최신 시각 |
|---|---:|---:|---:|---|---|
| M1 | `3,297,305` | `50,074` | `3,347,379` | `2020-03-25T10:36:00Z` | `2026-08-06T00:14:00Z` |
| M5 | `659,461` | `10,014` | `669,475` | `2020-03-25T10:40:00Z` | `2026-08-06T00:10:00Z` |
| M15 | `219,820` | `3,338` | `223,158` | `2020-03-25T10:45:00Z` | `2026-08-06T00:00:00Z` |

각 요청은 기존 마지막 봉 한 개를 겹쳐 받아 upsert했다. API가 반환한 행은 총
`63,429`개이고 실제 신규 고유 행은 `63,426`개다.

| 검사 | 결과 |
|---|---:|

| M1 간격 불연속 | `0` |

| M15 간격 불연속 | `0` |
| 비정상 OHLCV 행 | `0` |

| M1 재집계 대비 M15 불일치 | `0` |

검사 시점의 데이터베이스 크기는 `662,011,904` bytes이고 SHA-256은
`66e4313689d8e11bf096d174971a57dd48d97d23cda1b83f67ddcb7e6e931d4c`다.
데이터베이스 파일은 Git 추적 대상이 아니므로 이 해시는 해당 로컬 스냅샷의 감사
근거이며 배포 바이너리 식별자로 사용하지 않는다.

## 프로토콜 반영

`config/strategy-maximization-protocol-v1.json`의 `latestCandleAt`을 갱신하고
`closedThroughExclusive`를 추가했다. M1, M5, M15의 최신 봉 종료 시각이 이 공통
경계와 정확히 일치하는지 Node 회귀 테스트로 검증한다.

기존 봉인 구간 설정과 이미 작성된 과거 결과 보고서는 변경하지 않았다. 새로 추가된
기간은 다음 개발·검증 구간을 사전에 고정한 뒤에만 전략 평가에 사용한다.
