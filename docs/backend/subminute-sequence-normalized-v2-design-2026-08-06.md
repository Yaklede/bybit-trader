# 스프레드 정규화 5초 전략 v2 설계

## 문제

v1은 절대 microprice edge `0.05bps`를 확인 조건으로 사용했다. 2023 Q1에서 Q2로 넘어가며 평균 관측 스프레드가 `0.11383bps`에서 `0.03762bps`로 줄자 조건을 통과한 버킷이 `26,747개`에서 `5개`로 감소했다. 모든 후보가 최소 거래 수, Long 표본, 양수 분기 수를 충족하지 못했고 Q1 외 구간에서는 사실상 전략이 꺼졌다.

## 목표

- microprice 확인을 가격·tick·스프레드 크기에 덜 민감한 무차원 척도로 바꾼다.
- 기존 충격, OI, 유동성 보충, 체결, 진입·종료·비용·위험 계약은 변경하지 않는다.
- 새 후보 32개를 누적 trial ledger에 추가하고 2023 개발 결과만 평가한다.
- 통과 후보가 있을 때만 아직 읽지 않은 2024 내부 검증을 수집한다.

## 비목표

- v1 최고 수익 후보에 맞춰 임계값을 탐색하지 않는다.
- 최소 거래 수나 수익성 게이트를 낮추지 않는다.
- 같은 결과를 보고 stop, target, 보유 시간, 수수료를 바꾸지 않는다.
- 연구 통과만으로 자동 주문 또는 실거래를 허용하지 않는다.

## 특징 계약

완성된 5초 버킷에서 다음 값을 계산한다.

```text
closeSpreadBps =
  (closeBestAsk - closeBestBid) / closeMid * 10,000

normalizedMicroprice =
  clamp(meanMicropriceEdgeBps / (closeSpreadBps / 2), -1, 1)
```

스프레드가 0 이하이거나 교차된 장부는 확인 신호를 만들지 않는다. 방향을 곱한 정규화 값이 `0.2` 이상이어야 한다. 이상적인 동일 시점 top-of-book에서는 이 값이 수량 불균형과 같으므로 약 60:40 이상의 압력을 뜻한다.

원본 5초 집계는 평균 microprice edge와 종가 스프레드를 결합하므로 정확한 이벤트별 평균 top-1 imbalance는 아니다. 이 proxy 한계를 명시하고 값은 `[-1, 1]`로 제한한다. 다음 독립 단계에서 유효하지 않으면 후보를 폐기한다.

## 후보와 실행

- 가설군: 흡수 반전 16개, 고갈 지속 16개
- 누적 관측 후보: 이전 223개 + 신규 32개 = 255개
- setup grid: v1과 byte-equivalent
- 확인: 30초 내 방향 체결 불균형 `0.2` 이상, 방향 정규화 microprice `0.2` 이상, 방향 가격 이동
- 진입: 확인 다음 5초의 불리한 호가 + 0.02% 슬리피지
- 비용: taker 수수료 양쪽 각 0.06%, 슬리피지 양쪽 각 0.02%, 실제 펀딩
- 손절: `max(M1 ATR × 1.25, 체결가 × 0.4%)`
- 목표: 3R
- 최대 보유: 60분
- 수량: 계좌 위험 1%, 최대 명목가 100 USDT, 최대 레버리지 15배, 0.001 BTC 단위 내림

## 성공 지표

2023 선택 기준은 v1과 동일하다.

- 거래 24회 이상, Long·Short 각각 8회 이상
- 네 분기 중 세 분기 이상 양수
- profit factor 1.15 이상
- 평균 순 R 및 일별 moving-block bootstrap 95% 하한 0 이상
- MDD 15% 이하, 모의 청산 0
- 최대 승자 이익 집중도 35% 이하

가설군별 최대 한 후보만 동결한다. 통과 후보가 없으면 v2를 종료한다.

## 위험과 통제

- **개발 데이터 재사용:** 2023은 이미 v1에서 관측했다. 이를 명시적 개발 자료로 취급하고 신규 32회를 모두 trial ledger에 기록한다.
- **proxy 왜곡:** 평균 edge와 종가 spread의 시점 차이는 clamp와 독립 2024 검증으로 통제한다.
- **다중 시험:** v2 결과를 보고 후보 예산이나 임계값을 늘리지 않는다.
- **구간 과적합:** 2024 내부 검증 전에는 후보를 확정하고 파라미터를 수정하지 않는다.
- **실행 격차:** 향후 통과하더라도 비용·지연·자본 스트레스, Kotlin parity, Shadow/Paper 전진 검증 전까지 실행을 막는다.

## 완료 조건

선언 파일과 부모 증거 해시가 검증되고, 32개 후보가 고정 grid로 확장되며, v2 결과를 보기 전에 protocol commit이 원격 `main`에 존재해야 한다. 이후에만 2023 normalized replay를 한 번 수행한다.

## 선택 결과

32개 후보는 모두 비용 차감 후 손실이었고 선택 후보는 `0개`다. 정규화로 후보별 거래 수는 24~120회로 늘어났고 양방향 표본도 확보됐으므로 v1처럼 조건이 특정 분기에만 꺼지는 문제는 해소됐다. 그러나 순수익 범위는 `-18.08090%~-2.92004%`, 평균 순 R 범위는 `-0.65633~-0.16244`, profit factor 범위는 `0.03894~0.57024`였다.

최상위 순손익 후보의 bootstrap 95% 구간은 `-0.49993R~-0.02867R`로 상한도 음수다. 비용 전 가장 나은 흡수 후보는 평균 `+0.05971R`이었지만 평균 수수료 비용이 `0.22215R`이었고 비용 전 양수 분기도 2개뿐이었다. maker 체결을 가정해 수수료만 제거해도 강건한 후보가 되지 않는다.

v2 프로그램은 `CLOSED_NO_APPROVABLE_SUBMINUTE_SEQUENCE_STRATEGY_V2`로 종료한다. 동일한 충격 조건이나 종료 grid를 결과에 맞춰 다시 조정하지 않는다. 2024 및 이후 증거는 읽지 않았고 자동·실거래 권한은 닫힌 상태다. 후속 연구는 관측 비용보다 충분히 큰 경제적 edge를 갖는 별도 저회전 가설이어야 한다.
