# 비대칭 군집 흡수 반전 v3 결과

## 판정

v3의 공식 판정은 **가족 게이트 탈락**이다. nested walk-forward는 6개 반년 중 4개가 양수였지만 pooled 거래가 28건이었고 bootstrap 하한이 `-0.00218R`로 0을 근소하게 밑돌았다. 첫 fold에서 학습 적격 후보를 선택하지 못한 것도 실패 조건이다.

## 실행 정정

revision 1의 0거래 실행은 무효다. 단일 가족에서 M15 기울기 lookback이 0으로 계산돼 모든 M15 regime이 중립이 된 재생기 결함이었다. 후보 결과는 한 건도 관측되지 않았다. revision 2와 Git `cfea633`에서 닫힌 M15 4봉 기울기를 명시하고 회귀 테스트를 추가한 뒤 유효 결과를 다시 만들었다.
