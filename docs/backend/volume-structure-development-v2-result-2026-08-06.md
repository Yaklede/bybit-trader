# 거래량 구조 전략 v2 결과

## 판정

v2도 **탈락**이다. 돌파 재시험 지속형은 충분한 거래에서 음수 기대값이 확인됐고, 군집 소진 반전형은 양수 후보가 있었지만 표본과 bootstrap 하한을 통과하지 못했다. 신규 봉인 구간은 열지 않았다.

## 돌파 재시험 지속형

최고 진단 후보 `vbr_rv2_lb12_rt15`는 130건, 승률 19.23%, 평균 `-0.2230R`, PF 0.5804였다. 총수익률은 -13.74%였고 bootstrap 90% 구간은 `-0.3530R ~ -0.0920R`였다. 돌파 직후 추격뿐 아니라 재시험 진입도 비용 차감 후 음수이므로 OHLCV 기반의 이 지속형 가족은 폐기한다.

## 군집 소진 반전형

`cve_rv2p25_lb24_cf4`는 다음 결과를 냈다.

| 항목 | 결과 |
|---|---:|
| 거래 | 32회 |
| 양수 반년 구간 | 4/6 |
| 승률 | 37.50% |
| 총수익률 | +1.80% |
| 평균 순 R | +0.1164R |
| Profit factor | 1.1955 |
| MDD | 2.16% |
| Bootstrap 90% 구간 | -0.1198R ~ +0.3537R |

방향별로 Long은 `+5.82R`, Short는 `-2.09R`였다. 더 낮은 거래량 기준 후보를 세부 분해하면 Long 소진은 상대 거래량 2.0 이상에서 개선됐고, Short 소진은 1.75~2.5의 중간 구간에서 상대적으로 나았으며 극단 거래량에서는 손실이 커졌다. 이는 극단적 상승 거래량이 하락 추세에서도 소진이 아니라 short squeeze의 지속일 수 있다는 가설과 일치한다.

이 관찰은 사후 분해이므로 그대로 승인 근거가 될 수 없다. 다음 단계에서 방향별 거래량 상태를 먼저 고정하고, 12개 후보만 새로 실행해야 한다.

## 방법 보정

희소 이벤트 전략에서 거래가 없었던 달을 손실 월로 세면 신호 품질과 활동 커버리지가 혼합된다. 다음 단계부터 다음을 분리한다.

- `activeMonthPositiveRatio`: 거래가 하나 이상 있었던 달 중 양수 월 비율
- `activeMonthCoverage`: 전체 달 중 거래가 있었던 달 비율

zero-trade 월을 숨기지는 않지만, 후보 학습 적격성은 active month의 손익 안정성으로 판단한다. 최종 가족 게이트의 거래 60건, 4/6 양수 fold, PF 1.10, bootstrap 하한 양수는 그대로 유지한다.

## 다음 단계

`ASYMMETRIC_CLUSTER_ABSORPTION_REVERSAL` 한 가족만 검증한다. Long은 높은 거래량 하한, Short는 중간 거래량 상·하한을 사용하고 나머지 셋업·체결·비용·손절·목표 계약은 v2와 동일하게 유지한다. 이 단계도 실패하면 OHLCV 군집 반전의 추가 임계값 탐색을 중단한다.
