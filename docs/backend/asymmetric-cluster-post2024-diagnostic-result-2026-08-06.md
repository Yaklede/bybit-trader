# 비대칭 군집 흡수 반전 2024년 이후 진단 결과

## 판정

후보 `acar_lrv2p1_smax2p5_cf4`는 **폐기**한다. 기본 비용에서도 평균 순손익과 Profit factor가 명확히 음수 기대값을 가리키며, 비용 2배 스트레스에서는 손실이 더 커졌다. 예약된 신규 봉인 구간은 열지 않았고 자동 실행은 계속 금지한다.

이 진단 구간은 과거 연구에서 이미 본 데이터이므로 독립 holdout은 아니다. 그럼에도 결과가 명확히 실패했으므로 후보를 탈락시키는 반증 자료로는 충분하다.

## 실패 해석

개발 구간에서 후보는 66회 거래, `+8.44%`, 평균 `+0.2505R`, PF `1.4822`였다. 2024년 이후에는 기본 비용 기준 평균이 `-0.2878R`로 바뀌었다. 표본 오차만으로 설명하기 어려운 이유는 90% bootstrap 상한도 `-0.0851R`로 0보다 작기 때문이다.

비용이 손실을 키우지만 실패 원인은 비용만이 아니다. 기본 비용에서 이미 PF가 1보다 훨씬 낮다. 상대 거래량, 캔들 거부 모양, M15 방향 조건의 관계가 개발 시기 이후 유지되지 않았다는 뜻이다.

분기별 결과도 안정적이지 않다. 기본 비용에서 2024년 2·4분기, 2025년 1·2·4분기가 손실이었다. 특히 2025년 1·2분기의 평균은 각각 `-1R`로 모든 거래가 손절됐다. 특정 시장 상태를 구분하지 못한 채 같은 흡수 반전 규칙을 적용한 것이 구조적 약점이다.

## 다음 조치

1. 이 후보와 같은 OHLCV 군집 임계값을 추가 조정하지 않는다.
2. 예약된 `fresh-sealed-validation-2026-08-v1` 구간을 이 후보에 사용하지 않는다.
3. M15-M5-M1 인과적 실행 코어는 유지하되, 진입 가설은 taker 체결 방향·호가 고갈/보충·청산 흐름을 쓰는 독립 가족으로 교체한다.
4. 이벤트 데이터가 없는 과거 구간은 OHLCV 프록시로 꾸미지 않고, 데이터가 존재하는 범위만 개발·검증 대상으로 선언한다.
5. 새 후보도 동결된 비용·위험·외부 검증 기준을 통과하기 전에는 Paper나 Live 주문을 허용하지 않는다.
