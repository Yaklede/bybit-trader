# 비대칭 군집 후보 2024+ 역사 진단 프로토콜

## 문제

v3 가족은 nested 게이트를 통과하지 못했지만, 거래 60건 이상인 인접 후보군이 개발 데이터에서 양수 기대값과 양수 bootstrap 하한을 보였다. 이 신호가 개발 구간에만 맞춘 결과인지 확인하지 않고 신규 봉인 구간을 소비하는 것은 부적절하다.

## 목표

- 후보 `acar_lrv2p1_smax2p5_cf4` 하나만 고정한다.
- 2024-01-01부터 2026-07-02 05:40 UTC까지 10개 분기에서 재현한다.
- 비용 1.0배, 1.5배, 2.0배에서 동일 주문을 평가한다.
- 무너지면 후보를 폐기하고 신규 봉인 구간을 보존한다.

## 비목표

- 이 구간을 독립 holdout 또는 봉인 검증이라고 부르지 않는다.
- 결과를 보고 후보 파라미터나 창 경계를 바꾸지 않는다.
- 통과 결과를 실거래 승인으로 사용하지 않는다.
- 예약된 `fresh-sealed-validation-2026-08-v1`을 읽지 않는다.

## 요구사항

- 후보 ID와 모든 전략 파라미터를 설정에 명시한다.
- M15/M5는 닫힌 봉만 사용하고 확인 이후 다음 연속 M1 시가에 진입한다.
- 손절 우선, gap 불리 체결, 양방향 수수료·슬리피지 계약을 유지한다.
- 비용 배수는 수수료와 진입·종료 슬리피지에 모두 곱한다.
- 각 분기와 전체 결과에 거래 수, 승률, 평균 R, PF, MDD, 청산, 단일 승리 기여도를 보고한다.

## 진단 통과 기준

- 기본 비용 거래 40건 이상
- 양수 분기 7/10 이상
- 기본 비용 PF 1.10 이상
- 기본 비용 평균 순 R과 bootstrap 90% 하한이 모두 양수
- 기본 비용 MDD 20% 이하, 청산 0건
- 단일 승리 기여 25% 이하
- 비용 2배에서도 평균 순 R 양수

모두 통과해도 상태는 `RETAIN_FOR_SEPARATE_FRESH_SEAL_DECISION_ONLY`다. 자동 실행과 실거래는 계속 금지된다.

## 위험

- 이 기간은 이전 연구에서 이미 결과를 본 적이 있어 분석자 독립성이 없다.
- 저빈도 후보라 분기별 표본이 작을 수 있다.
- 비용 2배 스트레스도 실제 변동성 급등 시 꼬리 슬리피지를 완전히 설명하지 못한다.
- OHLCV 기반 청산 근사는 거래소 이벤트를 직접 복원하지 못한다.
