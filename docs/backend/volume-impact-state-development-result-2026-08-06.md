## 다음 가설

동일 파라미터의 재튜닝은 하지 않는다. 다음 단계는 관측된 실패 원인을 바탕으로 별도 프로토콜을 사전 선언한다.

1. `VOLUME_BREAKOUT_RETEST_CONTINUATION`: 거래량 돌파 직후 추격하지 않고, 돌파 수준 재시험과 저거래량 흡수 뒤 M1 재수용에서 진입해 가격과 손익비를 개선한다.
2. `CLUSTERED_VOLUME_EXHAUSTION_REVERSAL`: 단일 M5 초고거래량 봉 대신 인접 봉의 누적 거래량과 가격 진행 실패를 사용해 희소 신호를 늘리되, M15 방향과 M1 거부 확인은 유지한다.

새 후보도 일복리 목표로 선택하지 않는다. 비용 차감 후 평균 R, 구간 양수 비율, bootstrap 하한과 MDD를 먼저 통과해야 하며, 통과 전까지 현재 자동 실행 프로필은 계속 승인 불가 상태다.
