# 이벤트 흐름 전략 연구 종료 보고서

## 최종 판정

현재 공식 Bybit M1 이벤트 집계 데이터와 인과적 시장가 실행 계약에서는 승인 가능한 수익 전략이 없다. 최종 상태는 `CLOSED_NO_APPROVABLE_EVENT_FLOW_STRATEGY`이며 자동 주문과 실거래는 허용하지 않는다.

## 최종 가족 결과

| 가족 | 핵심 판정 |
|---|---|
| 즉시 고갈 지속 | 최선 후보도 평균 R 음수 |
| 즉시 흡수 반전 | 일부 양수였으나 bootstrap 하한 음수 |
| 반대 흐름 확인 흡수 반전 | 개발 소표본 양수가 미조회 확장 구간에서 재현되지 않음 |
| 같은 흐름 확인 지속 | 2023년 16후보 전부 큰 폭 음수 |
| 고충격 스윕 실패 반전 | 2023년 bootstrap 구간 전부 음수 |
| 충격·눌림·재가속 지속 | 3.5R 목표에서도 2023년 18후보 전부 음수 |

최종 눌림·재가속 가족은 후보별 16~43거래, 순수익률 `-9.8854% ~ -3.6039%`, 평균 `-0.6324R ~ -0.3470R`, PF `0.1959 ~ 0.4728`이었다. 가장 높은 순위 후보의 bootstrap 95% 상한도 `-0.1428R`로 0 아래였다.

## 비용과 손익비

최종 후보는 목표를 3.5R로 늘려 목표 종료 5건에서 평균 `+2.3332R`를 남겼다. 그러나 손절이 25건이어서 큰 승리만으로 손실을 상쇄하지 못했다. 수수료 차감 전 평균도 `-0.1830R`였고 수수료가 `0.2223R`를 추가 차감했다. 따라서 수수료 절감이나 maker 전환만으로 양수 기대값이 되지 않는다.

## 연구 무결성

- 누적 후보는 사전 상한 192개 중 191개다.
- 남은 1회는 새로운 전략 가족의 강건성을 검증할 수 없으므로 사용하지 않는다.
- 2025 검증, 2026 외부, 2026년 7~8월 신규 봉인 데이터는 읽지 않았다.
- 2023년 선택 실패 후 2024년 결과로 후보를 사후 선택하지 않았다.
- 탈락 결과를 보고 수수료, 방향, 보유 시간, 목표 배수 문턱을 낮추지 않았다.

## 의미

이 결과는 자동매매로 수익을 낼 수 없다는 일반 명제가 아니다. 현재 보유한 `1분 단위 taker/L2 집계 + EMA M15 regime + 시장가 비용` 특징 집합에서 검증한 가설들이 수익 근거를 만들지 못했다는 뜻이다. 백테스트 문턱을 낮추거나 같은 데이터에서 후보 수를 계속 늘리면 수익 전략을 만드는 것이 아니라 우연히 좋아 보이는 조합을 고르게 된다.

## 다음 연구 조건

다음 연구는 기존 191회와 분리된 새 증거 계약으로 시작해야 한다.

1. 1분 집계가 숨기는 순서를 보존하도록 1~5초 또는 이벤트 시퀀스 특징을 재구성한다.
2. OI 변화, funding, liquidation event를 같은 exchange clock에 결합한다.
3. 새 데이터 snapshot과 후보 상한을 결과 조회 전에 커밋한다.
4. 개발 통과 후보만 2025 검증에 보내고, 그 뒤에만 2026 외부·신규 봉인을 연다.
5. 독립 검증과 비용·지연·자본 스트레스, shadow/paper 정합성을 모두 통과하기 전에는 실거래 프로필을 만들지 않는다.
