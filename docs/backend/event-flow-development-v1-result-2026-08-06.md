# 이벤트 흐름 개발 v1 결과

## 판정

`bybit-event-flow-development-v1`은 `REJECTED_EXECUTION_INCOMPATIBLE_ZERO_TRADES`로 종료한다. 이 결과는 전략 기대값이 음수라는 뜻이 아니라, 동결된 M1 ATR 손절과 비용 인지 위험 하한이 호환되지 않아 실제 진입이 한 건도 없었다는 뜻이다.

검증·외부·신규 봉인 이벤트 데이터는 읽거나 획득하지 않았다. 이 결과로 실거래나 자동 승격을 허용하지 않는다.

## 원인

대표 지속형 후보는 122개 신호를 만들었지만, `1.25 × M1 ATR` 손절 거리는 다음과 같았다.

| 분위수 | 손절 거리 |
|---|---:|
| 최소 | 0.00267% |
| 중앙 | 0.02533% |
| 90% | 0.06340% |
| 95% | 0.07545% |
| 최대 | 0.25297% |

동결된 최소 초기 위험 거리는 `0.4%`, 수수료와 슬리피지를 합친 왕복 비용은 약 `0.16%`다. 손절 거리 하한은 비용이 목표와 손실의 대부분을 차지하는 거래를 막기 위한 것이므로 이를 낮춰 거래를 강제로 만들면 안 된다.

## 다음 가설

다음 단계는 같은 신호를 그대로 두고 초기 손절 거리를 다음처럼 계산하는 별도 실행 가설이어야 한다.

```text
initialStopDistance = max(
  1.25 × causal M1 ATR,
  entryPrice × 0.4%
)
```

이는 v1 결과를 고치는 재실행이 아니라 32개의 신규 후보를 소비하는 v2 단계다. v2도 개발 중첩 검증을 통과하기 전에는 잠긴 데이터 획득이나 후보 승격을 허용하지 않는다.
