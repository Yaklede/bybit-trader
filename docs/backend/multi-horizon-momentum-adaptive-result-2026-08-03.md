# 멀티 호라이즌 모멘텀 단축 지평 실험 결과

## 판정

`multi-horizon-momentum-adaptive-development-v1`은 개발 구간에서만 양수인 후보를 만들었지만, 외부 검증에서는 `REJECTED`다. 개발 구간의 성과를 보고 외부 구간에 맞춰 다시 조정하지 않았다.

개발 단계 후보 제한은 24개였다. 두 지평 세트, threshold scale 2개, 합의 표 수 2개, 방향 모드 3개의 조합만 사용했고, 손절·트레일링·비용은 기준선과 동일하게 유지했다. 상위 후보는 다음과 같다.

```text
adaptive_momentum_1d_7d_14d_scale0.75_votes3_long_only
```

개발 구간의 양수 여부만으로 후보를 승격하지 않고, 사전 고정한 순위 기준으로 상위 후보 하나만 외부 검증했다.

## 해석

시간 지평을 30일에서 14일로 단축하면 거래 수와 개발 구간 성과는 증가하지만, 신규 시장 구간에서 방향 오류가 줄지 않았다. 따라서 다음 실험에서 지평·손절·위험률을 동시에 변경하지 않는다. 거래량 필터 하나만 추가해 신호의 질과 거래 감소 비용을 분리 측정한다.
