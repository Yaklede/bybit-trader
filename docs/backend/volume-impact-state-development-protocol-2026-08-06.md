# 거래량-가격충격 상태 전략 개발 프로토콜

## 문제

현재 운영 프로필은 인과적 재검증에서 비용 차감 후 기대값이 음수였고, 기존 연구 스크립트는 M5 배열에 M15 집계를 보조로 붙이는 구조라 `M15 방향 -> M5 셋업 -> 이후 M1 확인 -> 다음 M1 진입` 순서를 실행 계약으로 강제하지 못한다. 과거 2024년 이후 결과도 이미 여러 차례 열람했으므로 같은 구간을 새 독립 검증처럼 재사용할 수 없다.

## 목표

- 닫힌 M15, 닫힌 M5, 그 이후 M1 확인만 사용하는 인과적 재생기를 만든다.
- 거래량 증가를 방향 신호로 직접 해석하지 않고 가격 충격의 효율과 실패 상태를 분리한다.
- 지속형과 소진 반전형을 서로 독립된 가설로 검증한다.
- 2024년 이전 expanding nested walk-forward에서 후보 선택 과정 자체를 평가한다.
- 비용 차감 후 기대값이 검증된 후보만 다음 단계에 고정한다.

## 비목표

- 일복리 0.2% 또는 특정 총수익률을 후보 선택 목적함수로 사용하지 않는다.
- 승률만 높이거나 거래 횟수만 늘리는 튜닝을 하지 않는다.
- 이미 열람한 2024년 이후 구간을 독립 외부 검증이라고 부르지 않는다.
- 개발 단계에서 실거래, 자동 승격 또는 예약된 신규 봉인 구간 재생을 하지 않는다.

## 가설

### 거래량-가격충격 지속형

닫힌 M15 추세와 같은 방향으로 닫힌 M5가 이전 범위를 돌파하고, 거래량 대비 가격 변위와 종가 위치가 강한 경우에만 셋업을 무장한다. M5 종료 뒤 별도의 M1이 같은 방향의 후속 움직임을 확정해야 하며, 그 다음 연속 M1 시가에서만 진입한다. 수익은 고정 목표가로 제한하지 않고 M1 경로에서 갱신되는 ATR 트레일로 추세 종료까지 보유한다.

### 거래량 소진 반전형

닫힌 M5가 큰 거래량으로 이전 극값을 침범했지만 범위 안으로 복귀하고, 거래량 대비 방향성 변위가 작으며 거부 꼬리가 지배적인 경우에만 반전 셋업을 무장한다. M5 종료 뒤 별도의 M1이 거부 방향을 이어갈 때 그 다음 연속 M1 시가에서 진입한다. 지속형과 반대되는 가설이므로 한 규칙에서 두 상태를 사후 선택하지 않는다.

## 요구사항

- `config/volume-impact-state-development-v1.json`을 후보 실행 전에 커밋한다.
- 후보는 지속형 12개, 반전형 12개, 총 24개로 제한한다.
- 각 outer fold는 해당 validation보다 앞선 training 데이터에서만 후보를 선택한다.
- 모든 M15/M5 입력의 종료 시각은 M1 판단 시각보다 작거나 같아야 한다.
- M1 확인 봉은 M5 셋업 종료 시각보다 엄격히 뒤에 있어야 한다.
- 진입은 확인 봉 다음의 정확히 연속된 M1 시가이고 불리한 슬리피지를 적용한다.
- 동일 M1에서 손절과 유리한 종료가 모두 가능하면 손절을 먼저 적용한다.
- 진입과 종료 양쪽에 수수료와 슬리피지를 적용한다.
- 개발 수량은 연속 수량으로 비교하되, 최소 수량·수량 간격·100 USDT 자본 적합성은 M6에서 별도 스트레스한다.
- 실패한 가족의 파라미터 그리드를 같은 단계에서 확장하지 않는다.

## 성공 지표

가족별 nested validation 합산 결과가 다음을 모두 충족해야 한다.

- 6개 중 양수 validation fold 4개 이상
- validation 종료 거래 60건 이상
- 비용 차감 후 평균 순 R이 0 초과
- profit factor 1.10 이상
- 순 R moving-block bootstrap 90% 하한이 0 초과
- 합산 최대 낙폭 20% 이하
- 모의 청산 0건

일복리와 총수익은 보고 항목이며 승인 조건을 대신하지 않는다. 개발 게이트를 통과해도 실거래 승인이 아니며, 후보 소스·설정·시뮬레이터를 고정한 뒤 비용 및 자본 스트레스, 예약 봉인 검증, Shadow/Paper 전진 검증을 추가로 통과해야 한다.

## 위험

- OHLCV만으로 taker 방향, 호가 보충, 강제청산 원인을 직접 관측할 수 없다.
- 24개 후보도 다중 시험 편향을 만들므로 누적 trial 수를 연구 manifest에 포함해야 한다.
- 2024년 이후 시장 결과를 이미 열람했기 때문에 장기 역사 구간은 강건성 진단일 뿐 완전한 독립 holdout이 아니다.
- M1 OHLC 안에서 이벤트 순서를 완전히 알 수 없으므로 충돌 시 손절 우선은 보수적 근사다.
- BTC 최소 수량 때문에 100 USDT 계좌에서는 유효 후보도 위험 예산 안에서 주문하지 못할 수 있다.

## 단계 종료

두 가족이 모두 실패하면 예약된 `fresh-sealed-validation-2026-08-v1`을 열지 않고 `REJECTED` 결과를 남긴다. 하나 이상 통과하면 전체 2024년 이전 데이터에서 사전 순위 규칙으로 가족당 최대 한 후보를 선택하고, 코드와 파라미터 fingerprint를 커밋한 다음에만 다음 검증 단계로 이동한다.
