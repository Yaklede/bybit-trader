# 비용 회수형 carry v3 2026 상반기 봉인 검증 계획

## 목적

2023~2025 개발 구간에서 선택한 `multi_asset_cost_recovery_carry_018`을 변경하지 않고
2026-01-01부터 2026-06-30까지의 미열람 공식 Bybit 데이터에 한 번만 재생한다. 이 단계는 개발
구간 선택 편향을 검사하기 위한 외부 검증이며 목표 수익률을 맞추는 튜닝 단계가 아니다.

## 데이터 계약

- 자산: BTCUSDT, ETHUSDT, SOLUSDT
- 입력: 현물 last, 무기한 선물 last, mark, index의 5분봉과 8시간 funding settlement
- 기간: `[2026-01-01T00:00:00Z, 2026-07-01T00:00:00Z)`
- 블록: 2026 Q1, 2026 Q2
- 원본 REST 응답, 정규화 행, coverage, snapshot을 각각 SHA-256으로 봉인
- 한 시계열이라도 5분 간격이 누락되거나 시계열 timestamp가 다르면 결과 재생 금지

## 사전 통과 기준

| 항목 | 기준 |
|---|---:|
| 종료 포지션 | 3개 이상 |
| 활성일 | 90일 이상 |
| funding settlement | 270개 이상 |
| 거래 자산 | 2개 이상 |
| 수익 자산 | 2개 이상 |
| 양수 분기 | 1 / 2 이상 |
| 순수익·평균 일수익·bootstrap 하한 | 모두 0 초과 |
| PF | 1.1 이상 |
| MDD | 5% 이하 |
| 청산 | 0회 |
| 비용 1.5배·2차 leg 지연 | 모두 순수익 0 초과 |

포지션 수익 집중도는 0.60, 자산 수익 집중도는 0.75 이하로 제한한다. 현물과 선물 수량 차이는
자산별 거래 단위 이내여야 한다.

## 결과 정책

한 항목이라도 실패하면 후보 018을 폐기한다. 결과를 본 뒤 이 구간의 기준, 후보 파라미터, 기간을
변경하지 않는다. 통과하더라도 실거래를 허용하지 않으며, 공유 실행 코어의 spot/perpetual 원자적
체결, 재시작 복구, shadow 및 paper 전진 검증을 별도로 통과해야 한다.
