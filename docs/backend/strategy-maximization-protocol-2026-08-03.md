# 전략 최대화 연구 프로토콜

## 목적

기존 백테스트 결과를 더 높은 수치로 보정하는 것이 아니라, 닫힌 캔들만 사용하는 인과적 실행 계약과 실제 비용을 고정한 상태에서 여러 시장 구간에 견디는 전략 후보를 찾는다. 이 문서와 설정은 연구 기준이며 실거래 승인을 의미하지 않는다.

## 고정 기준

- 원천 데이터: `build/runtime-test/bybit-trader-full-history.sqlite`
- 대상: `BTCUSDT`, `M1/M5/M15`
- 진입: 신호가 확정된 다음 연속 캔들 시가, 불리한 슬리피지 적용
- 동일 캔들에서 손절과 목표가 모두 닿으면 손절 우선
- 다음 캔들이 없거나 시간 간격이 끊기면 `NO_TRADE`
- 진입·청산 수수료와 슬리피지는 양쪽에 모두 적용
- 백테스트와 런타임이 동일한 실행 계약을 사용해야 한다

## 수익률 목표의 위치

일복리 0.2%는 전략을 찾기 위한 최적화 목적함수가 아니다. 이 수치를 직접 최대화하면 특정 구간을 설명하는 후보를 고르는 방향으로 과적합될 수 있다. 후보 승인 시 비용 차감 후 기대값, 외부 구간 양수 비율, 최대 낙폭, 청산 횟수, 비용 스트레스 결과를 먼저 확인하고 일복리 수치는 결과로 보고한다.

## 단계별 실험 제한

- 단계별 신규 후보는 최대 24개
- 연속 조정 단계는 최대 4회
- 실패한 단계에서 파라미터 그리드를 확장하지 않음
- 학습 구간에서만 파라미터를 선택
- 봉인 구간은 승인 시점까지 열람하지 않음
- 자동 승격과 연구 프로필의 실거래 실행을 허용하지 않음

기존 `multi-horizon-momentum-development-v1`의 108개 후보는 비교 기준으로만 보존한다. 새 후보는 위 제한 안에서 별도 실험으로 취급한다.

## 승인 게이트

최소 8개 외부 워크포워드 구간을 사용하고, 다음을 모두 검사한다.

- 외부 양수 구간 비율 75% 이상
- 종료 거래 200건 이상
- 기본 최대 낙폭 30% 이하
- 비용 2배 스트레스 최대 낙폭 40% 이하
- 모의 청산 0건
- 기대값 부트스트랩 하한 0R 초과
- 한 거래가 전체 이익의 25%를 초과하지 않음
- 거래당 위험 0.25%, 0.5%, 0.75%, 1.0%에서 결과를 분리 보고

모든 게이트를 통과하지 못하면 전략을 승격하지 않고, 실패 원인을 기록한 뒤 다음 가설로 이동한다.
