# 델타 중립 carry 시뮬레이터 basis 판정 수정

## 판정

최초 2023 개발 재생 결과는 공식 결과로 사용하지 않는다. 후보나 비용 조건의
문제가 아니라, M5 봉 내부에서 동시 발생 여부를 알 수 없는 현물 저가와 선물
고가를 하나의 basis 관측값으로 결합한 실행 모델 오류가 발견됐기 때문이다.

예를 들어 2023-08-17 거래는 한 M5의 현물 저가 `24,431`과 선물 고가
`27,595.6`을 결합해 basis 확대 손절로 처리됐다. 두 극값의 시각은 제공된 OHLC로
확인할 수 없으므로 실제 13% basis가 관측됐다는 뜻이 아니다. 일반적인 BTC
급락만으로 델타 중립 pair에 존재하지 않는 손실이 만들어졌다.

## 수정 계약

- mark 고가가 보수적 청산 경계를 넘으면 intrabar 청산으로 처리한다.
- basis는 같은 M5의 현물 종가와 선물 종가로만 계산한다.
- 종가 basis가 진입 basis보다 3% 확대되면 다음 M5 시가에 두 leg를 종료한다.
- 현물 저가와 선물 고가를 결합한 가상 basis는 사용하지 않는다.
- 후보 24개, candidate hash, funding 조건, 보유 기간, 비용, 자본, 승인 게이트는
  변경하지 않는다.

이 수정은 개발 결과에 맞춘 파라미터 조정이 아니라 관측 불가능한 동시성을
제거하는 인과성 수정이다. 수정 구현과 회귀 테스트를 먼저 커밋한 뒤 같은 봉인
snapshot을 다시 재생한다.
