# 이벤트 흐름 확인형 지속 v1 결과

## 판정

확인형 고갈 지속 전략은 `REJECTED_ACCEPTED_CONTINUATION`으로 종료한다. 2023년 선택 구간에서 16개 후보가 모두 음수였으므로 선택 후보가 없고, 2024년 결과로 후보를 다시 고르는 것도 금지한다. 검증·외부·신규 봉인 데이터와 자동 주문 권한은 계속 잠근다.

## 메커니즘 해석

이 전략은 강한 taker 체결, 같은 방향 top-5 호가 압력, 반대편 호가 고갈이 발생한 뒤 추가 체결과 셋업 고저점 돌파까지 확인하고 추격했다. 그럼에도 2023년 전 후보가 크게 음수였다. 즉, 확인을 추가해도 진입 시점에는 가격 지속의 상당 부분이 이미 소진됐고 손절·시간 종료에 비해 남은 보상이 작았다.

가장 덜 나쁜 후보의 전체 개발 종료 분포는 손절 22건, 목표 8건, 시간 종료 36건이었다. Long 평균은 `-0.2107R`, Short 평균은 `-0.2722R`로 양방향 모두 음수였다. 특정 방향 차단만으로 고칠 수 있는 문제가 아니다.

2024년에는 16개 후보의 평균 R이 모두 양수였지만 후보별 거래가 8~17건에 불과했다. 사전 계약은 2023년에서 한 후보를 선택한 뒤 그 후보만 2024년에 적용하도록 정했다. 2023년 선택 자격을 통과한 후보가 없으므로 2024년 소표본을 보고 후보를 사후 선택하면 안 된다.

## 데이터 시대 점검

수집 데이터의 일평균 L2 메시지는 2023년 약 859,676건, 2024년 약 863,609건이고 snapshot 빈도도 동일했다. 2024년의 평균 spread와 microprice edge는 더 작았지만 이는 더 촘촘해진 시장 유동성과 함께 나타났다. 현재 증거만으로 2023년 손실을 importer 오류로 돌릴 근거는 없으며, 절대 bps 특징의 시대 민감성은 다음 후보에서 고정 임계값 대신 가격 경로의 실패 여부로 줄인다.
