# Bybit Trader

이 저장소는 Rust로 다시 시작한 연구 프로젝트입니다.

**현재 승인된 전략과 검증된 수익률은 없습니다.** 주문, 거래소 연결, API,
대시보드, 배포 기능도 없습니다. `cargo run`은 상태만 출력하며 주문하지 않습니다.
일복리 1%는 연구 목표이지 예상 수익률이 아닙니다.

```sh
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo run
```

기존 전략 코드와 연구 보고서는 작업 공간에서 제거했습니다. Git 이력에는 남아
있지만 새 전략의 검증 근거로 사용하지 않습니다. AOA 원본 압축 파일은 체결
관찰 자료일 뿐, 주문하지 않은 시점이나 당시의 판단을 기록하지 않습니다.

기존 `.env`와 `data/legacy-inputs/`의 자료는 보존했지만 새 코드는 읽지 않습니다.
격리된 자료의 출처와 품질을 검증하기 전에는 연구 입력으로 사용하지 않습니다.
이 저장소의 로컬 변경은 이미 배포된 서버를 중지하거나 교체하지 않습니다.
